### 3. Linux（15-20 分钟）：基础导航命令

打开你的终端（WSL/Ubuntu 或 Git Bash），实际操作以下命令：

```
pwd          # 我在哪
cd ~         # 回家目录
cd ..        # 上一级目录
ls           # 列出文件
ls -l        # 详细列表
ls -a        # 显示隐藏文件
cat 文件名    # 查看文件内容
```

练习：用 `cd` 在不同目录间切换，用 `ls` 查看内容，用 `cat` 查看几个文本文件。
